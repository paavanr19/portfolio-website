Projects

  • Rubik's Cube Solver

    View project

    A Rubik’s Cube solving program that takes a cube configuration as input and uses the two-phase Kociemba algorithm to calculate an efficient solution. It parses cube states from files, processes the cube configuration, and generates step-by-step instructions for solving the cube.

  • Pocoloco

    View project

    A multiplayer dice game where players compete to be the first to lose all of their chips. The game features randomized turn order, custom scoring mechanics, and special dice combinations such as Poco, Loco, and three-of-a-kind rolls. It processes each player's dice rolls, applies the corresponding scoring rules, and updates chip counts throughout each round.

  • Mythos Seafarer

    View project

    A Java-based arcade-style game built using Processing. Players navigate through multiple levels, avoid enemies, collect rewards, and progress through different maps. The game features interactive gameplay, level progression, and increasing challenges as players advance.

  • Unix Shell

    View project

    A Unix-style command-line shell in C with support for process creation and execution, foreground and background processes, built-in commands, signal handling, and command history. Process management uses fork(), exec(), and waitpid(), with Linux system calls and CMake for configuration and builds.
